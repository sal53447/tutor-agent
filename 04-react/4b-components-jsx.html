What JSX actually is

// JSX:

hi


// Compiles to:
React.createElement("div", { className: "box" },
  React.createElement("span", null, "hi")
);

JSX is syntactic sugar for function calls that build a plain JS tree of "element" objects. Nothing magical. That also explains why className (not class) and onClick (not onclick) — they're JS object keys, not HTML attributes.

Fragments

Components must return a single root element. When you don't want an extra DOM node, use a Fragment.

// Both forms are identical; short form can't take props (e.g., key=)

Refs in React 19

ref is now a plain prop for function components. forwardRef is no longer needed — just accept ref directly.

// React 19 — no forwardRef wrapper needed
function Input({ ref, ...props }) {
  return ;
}

// Usage unchanged:
const inputRef = useRef(null);

Class components still require forwardRef; function components do not.

Composition patterns

  • Children — the standard slot. <Card>contents</Card>
  • Named slots — pass React nodes as props: <Layout header={...} sidebar={...}>
  • Render props — a function as children: <Mouse>{({x,y}) => ...}</Mouse>. Mostly replaced by hooks.
Conditional render pitfall — the 0 problem

count && <Badge /> renders the number 0 when count is 0 because 0 is falsy but JSX renders it as text. Use a ternary or explicit boolean: count > 0 && <Badge /> or !!count && <Badge />.

Python bridge

JSX looks like HTML templates (Jinja2, Django templates) but compiles to plain function calls — closer to a Python data-class builder than a template engine. There's no template "scope"; everything is just JavaScript expressions. Conditionals and loops are JS ternaries and .map(), not {% if %} / {% for %}.

Review flags
  • Putting conditionals in JSX with if. Use condition && <X/> or ternaries.
  • Missing or non-unique key in lists. The fastest way to silently break lists.
  • Mutating props. Never do this. Props are read-only inputs.
  • Defining components inside other components. Every render creates a new component type → total state loss on re-render.
