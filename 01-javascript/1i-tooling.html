Part 1 · JavaScript · 1i

Tooling Ecosystem

Package managers: npm, pnpm, yarn

  • npm — ships with Node, ubiquitous. Fine.
  • pnpm — uses a content-addressable store, much faster, disk-efficient. De facto standard at many teams. Recommended.
  • yarn — yarn 1 is legacy; yarn 3+ (Berry) exists but has niche adoption. Yarn's innovations (lockfile, workspaces) have been absorbed by npm/pnpm.

package.json essentials

{
  "name": "my-app",
  "version": "0.1.0",
  "type": "module",
  "main": "dist/index.js",
  "scripts": {
    "dev": "vite",
    "build": "vite build",
    "test": "vitest",
    "lint": "eslint ."
  },
  "dependencies": { "express": "^4.19.0" },
  "devDependencies": { "vite": "^5.0.0" },
  "engines": { "node": ">=20" }
}

peerDependencies

A package lists a peer dependency when it expects the host project to provide that package rather than installing its own copy. Example: a React component library lists react as a peer — it needs React, but using a second copy would break hooks and context.

{
  "peerDependencies": {
    "react": ">=18"
  }
}

If you publish a library: use peerDependencies for framework deps (React, Vue, etc.). If you consume a library: your package manager will warn if required peers are missing — install them in your own dependencies.

npx and pnpm dlx — one-off tool execution

Run a package binary without installing it globally:

npx create-next-app@latest my-app   # npm's one-off runner
pnpm dlx create-next-app@latest my-app  # pnpm equivalent — no cache pollution

pnpm dlx is preferred in pnpm projects: it isolates the temporary install and never touches your project's node_modules.

Semver and lockfiles

  • ^1.2.3 — any 1.x.x >= 1.2.3. Most common.
  • ~1.2.3 — any 1.2.x >= 1.2.3.
  • 1.2.3 — exact.

The package-lock.json / pnpm-lock.yaml pins the exact tree. Commit lockfiles. npm ci installs exactly what's in the lockfile — use this in CI.

Bundlers and transpilers

  • Vite — the default for most new projects. esbuild-powered dev, Rollup-powered build.
  • esbuild — extremely fast. Often used as a library inside other tools.
  • Turbopack — Next.js's new bundler (Rust-based, replacing webpack).
  • webpack — legacy but still widely deployed.
  • SWC / Babel — transpile modern JS/TS to older JS. SWC is Rust, faster; Babel is JS, more plugins.
Code review
  • Pin engines. A project that works on Node 22 but not 18 needs "engines": { "node": ">=22" } in package.json.
  • Keep devDependencies and dependencies correctly separated. Shipping a linter at runtime bloats bundles.
  • Use npm ci / pnpm install --frozen-lockfile in CI, never npm install.
