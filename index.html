A curriculum for Python engineers learning JS, TS, Express, React, and Next.js

Fifty-three lessons across five parts. Written for engineers with real Python / data experience who want the idioms, trade-offs, and production patterns — not a beginner tutorial.

JavaScript is the runtime model — values, scope, async, and the event loop — and every later part assumes you understand it. TypeScript adds static correctness on top of those same object shapes. Express applies both on the server at production depth: routing, auth, databases, and observability. React is the dominant UI layer and expects JS and TS fluency. Next.js then unifies the server and client into one framework, drawing on all four parts simultaneously.

Prerequisites: comfort with a terminal (CLI), git, a code editor, and a conceptual grasp of HTML, CSS, and HTTP — you don't need to be an expert, but the lessons don't explain these from scratch.

Each lesson lives in its own page. Your progress is tracked locally in your browser. Use J / K or arrow keys to move between lessons while reading.
